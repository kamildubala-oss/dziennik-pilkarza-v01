# Redakcja instrukcji ćwiczeń 2.4

Każde z 72 ćwiczeń ma własny krótki `description` i cztery konkretne kroki: przygotowanie stanowiska, wykonanie ruchu, ciąg dalszy i zmianę strony lub wariant. Informacje o rozstawieniu znaczników są częścią instrukcji, nie osobnymi akapitami „Sprzęt” i „Przestrzeń”. Poprawiono również cztery starsze karty treningowe; zaakceptowane „Prowadzenie piłki” pozostaje bez zmian.

Karty gotowych treningów, nowe plany offline i odpowiedzi z bazy korzystają z tych samych opisów. Istniejące zapisane plany i wpisy nie są nadpisywane.

Identyfikatory, czas bloków i intensywność zachowano. Pola źródłowe `instructions`, `work_rest`, ograniczenia wieku i pochodzenie pozostają metadanymi; nie są bieżącą instrukcją widoczną na karcie. Ćwiczenie komunikacji wspierającej opisuje pracę z partnerem, dlatego jego metadane wskazują dwie osoby. Baza nadal nie wymaga większej grupy. `content_revision: clear_steps_v1` oznacza redakcję tekstu, a nie zatwierdzenie programu przez federację.

Ponowny import pierwotnej paczki zachowuje redakcję dzięki identyfikatorowi `import_origin`; importer nie obniża nowszej wersji schematu.
