# Specyfikacje trenera offline — dokumentacja, nie zasoby aplikacji

Te pliki opisują **proponowane** modele obciążenia, planowania tygodnia, analizy trendów, odpowiedzi offline oraz informacje o źródłach i prawach. Kod Flutter ich nie wczytuje ani nie realizuje automatycznie wszystkich opisanych reguł.

Aktywnie używana biblioteka ćwiczeń znajduje się w `assets/offline_coach/exercise_library_v2.json`. Przykładowy plan w `weekly_planner_v2.json` ma poprawione odwołanie `tech_scan_receive`. Nie traktuj specyfikacji jako zaimplementowanych funkcji.
